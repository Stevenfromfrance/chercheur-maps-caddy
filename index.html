Guide atelier — 8 étapes cliquer pour ouvrir / fermer

Lis dans l’ordre. Les adresses bleues se copient pour WinOLS (Ctrl+G).

  1. Comprendre la page : choisis la paire en haut — ORI vs ACE (Stage1 prépa), ORI vs V1 (ta carto), ACE vs V1 (écart V1 sur ACE). Chaque adresse = une map WinOLS.
  2. V1 = base ACE + AccPed/tqlim/rail/smoke (partiels soft, WOT ~350 Nm, hardcut 4800). Deletes FAP/EGR ACE inchangés.
  3. Cible atelier ≠ ACE brut : ACE pousse wish/smoke vers ~350–400 Nm. V1 plafonne le WOT à ~350 avec pédale plus calme.
  4. Atlas DTC : section DTC atlas = tableau compact des P-codes DaVinci + reste fonction 0x180xxx.
  5. Hors A2L = mélange DTC deletes + suites Stage1 (rail…) + calib — pas « deletes seulement ». Filtre famille Deletes ACE pour les P-codes.
  6. WinOLS : charge ORI en version « Original », puis ACE .NOCS en 2ᵉ version (même SW 9979).
  7. Clique une adresse bleue ici → elle se copie → dans WinOLS Ctrl+G → coller → Entrée.
  8. Bascule Original / ACE : les cases jaunes = ce qu’ACE a modifié.
  9. Vue 2D ci-dessous = même grille que WinOLS (valeurs physiques). Mode Écart = zones touchées.
  10. Après flash : enregistre un log VCDS (section verte) pour vérifier les plafonds des maps.

Validation log VCDS

replié — ouvrir si tu as un CSV
À quoi ça sert ? Après (ou avant) une reprog, tu enregistres ce que l’ECU mesure en roulant. Ici on compare les pics du log aux plafonds du fichier ACE (valeurs max des maps Stage 1). Vert = dans les clous · Orange = limite · Rouge = dépassement à traiter.
  1. Dans VCDS → module moteur → Advanced Measuring Values → coche RPM, couple, MAP consigne/réel, rail consigne/réel, air mass.
  2. Fais un essai : accélérations franches (plein gaz en montée de régime), puis Log → Save as CSV.
  3. Ici : Charger fichier… (ex. STEVENCADDYLOG1.CSV) ou colle le contenu → Analyser.
  4. Lis le bilan atelier en bas : il te dit quoi vérifier dans WinOLS ensuite.
Vert = OK sous plafond ACE Orange = proche / un peu au-dessus → regarder la map Rouge = dépassement clair → risque / map ou méca
