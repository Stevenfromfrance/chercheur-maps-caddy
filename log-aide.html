Log VILLE — confort / partiels

But

Vérifier conduite douce (pas on/off ACE).

IDE

Conditions

  • 15–20 min ville
  • ASR ON
  • Pas de WOT long

Séquence

  1. 01-Engine → Advanced Measuring Values
  2. Coche les IDE → Log Start
  3. Conduite normale
  4. Stop → Save → CADDY_VILLE_YYYYMMDD.CSV

Log ROUTE — Stage1 / rail / turbo

But

Couple ~320–340 · rail réel ≤1650–1670 · MAP cohérent

IDE

Conditions

  • 3ᵉ ou 4ᵉ, moteur chaud
  • Route dégagée
  • ASR ON

Séquence

  1. Coche IDE → Log Start
  2. Plein gaz ~1800 → 3500–4000 en charge
  3. 1–2 runs
  4. Stop → Save → CADDY_ROUTE_WOT_YYYYMMDD.CSV

Interdit : seulement frein moteur / décélération.

Log DEPART — launch frein à main

But

Hold régime + MAP/couple au hold + comportement au départ.

IDE

Conditions

  • Endroit sûr
  • ASR OFF
  • 1ʳᵉ + frein à main + en prise (pas débrayé au hold)

Séquence

  1. Log Start
  2. Plein gaz 2–3 s (noter hold RPM)
  3. Départ contrôlé
  4. Stop → Save → CADDY_DEPART_LAUNCH_YYYYMMDD.CSV

Log HARCUT — ~4800 en roulant

But

Couple → 0 vers ~4800 avec vitesse > 0.

IDE

Conditions

  • 3ᵉ/4ᵉ, pas launch
  • Vitesse > 0

Séquence

  1. Log Start
  2. Montée franche jusqu’à zone 4500–4800
  3. Stop → Save → CADDY_HARCUT_YYYYMMDD.CSV
