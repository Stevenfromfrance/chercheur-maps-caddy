# Short #10 : Left Column = The Address

**Durée :** ~15 sec | **WinOLS basics** | **Prérequis :** Shorts #8–#9

## 🎯 Objectif

Localiser **où** se lit l'adresse dans le hexdump WinOLS.

## 🔍 Phrase Clé

> **LEFT COLUMN the address**  
> **LOCATED HERE**

## 📐 Layout

```
┌ ADRESSES ┬  DATA HEX (16 cols)  ┬ Preview ┐
│  gauche  │  centre              │ droite  │
└──────────┴──────────────────────┴─────────┘
     ↑ ICI
```

1. Colonne **gauche** = adresse
2. Centre = octets
3. Droite = aperçu

## ✅ Workflow

1. Noter adresse map (ex. `1D1496`)
2. Go to adresse (colonne gauche)
3. Créer map / appliquer factors
