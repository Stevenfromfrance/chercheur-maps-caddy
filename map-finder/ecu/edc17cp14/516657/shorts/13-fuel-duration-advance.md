# Short #13 : Fuel Duration & Advance

**Durée :** ~40 sec | **Lesson 21**

## 🎯 Objectif

Lier couple → fuel : **duration (µs)** + **timing (° BTDC)**.

## 🔍 Phrase Clé

> Torque = fuel (Torque-to-IQ). More fuel requires more advance.

## 📐

| | |
|---|---|
| Duration | µs selon rail + mm³ — more duration = more fuel |
| Timing + | Advance (avant TDC) |
| Timing 0 | TDC |
| Timing − | Retard |
