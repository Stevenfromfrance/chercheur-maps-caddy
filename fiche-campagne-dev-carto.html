Campagne logs — penser à tout

Objectif : décider si on peut lisser le haut de courbe (après ~3900) sans trop fumer / sans risque. Chaque run = une question. Même route banc pour tous les ROUTE_*.

Détail cliquable aussi dans log-aide.html (packs DEV).

Rafraîchissement IDE — réponse nette

Oui tu as le droit d’augmenter le nombre d’IDE — mais chaque canal supplémentaire ralentit le multiplexe. Avec tes réglages (Blk Int 25 / Char Int 0 / Group UDS + peu d’IDE) tu es ~0,2 s. Repasser à 9–12 IDE → souvent ~1–2 s comme avant.

  • Règle campagne : 4 à 6 IDE max par fichier (idéal 4–5).
  • Ancres toujours : RPM + pédale + TQI_SP (+ vitesse si route/launch).
  • Même pull, plusieurs fichiers : ROUTE_CLIFF puis sans bouger la route ROUTE_AIR, etc.
  • Ne fais pas un seul log « tout coché » — ça tue la preuve du cliff.

Options VCDS (garder)

  • 01-Engine → Advanced Measuring Values
  • Options : Blk Int 25 · Char Int 0 · Group UDS si dispo
  • Décoche TOUT sauf la liste du run

Avant la session (checklist)

Sonde ADVMB (1 fois, 2 min)

Cherche dans la liste ADVMB (filtre) — si présent sur 9979, note le nom exact et on fera un pack dédié. Ne invente pas si absent :

  • Limiting torque / torque limitation
  • Mean injection quantity / Injection quantity
  • Exhaust gas temperature / EGT
  • Start of injection / SOI

Ordre de session recommandé

  1. FAP_BEFORE (30 s)
  2. CALAGE (ralenti)
  3. VILLE_TIPIN
  4. VILLE_PARTIEL
  5. ROUTE_CLIFF ★ cliff 3k→4.6k
  6. ROUTE_AIR ★ air vs couple
  7. ROUTE_RAIL
  8. ROUTE_VNT
  9. ROUTE_INJ + note fumée
  10. ROUTE_DENSITE
  11. DEPART_HOLD
  12. DEPART_DUMP
  13. HARCUT
  14. A100
  15. FAP_AFTER
  16. ROUTE_HOT (autre moment, jour chaud)

★ = critiques pour décider le fill haut régime. Les autres sécurisent rail / VNT / FAP / launch.
