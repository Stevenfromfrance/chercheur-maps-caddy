**Anderson Connectors :**
```
Aliexpress : "Anderson SB350 connector"

SB350 (350A) : 15-30 USD la paire ✅ Recommandé
```

**XT Connectors (alternatives) :**
```
⚠️ XT90 = 90A max → Insuffisant
Besoin : XT150 ou supérieur
Prix : 5-15 USD la paire
```

#### Câbles haute section

**Amazon/Aliexpress :**
```
Recherche : "10 AWG silicone wire red black"
Recherche : "8 AWG battery cable"

10 AWG (6mm²) : ~2-3 USD/mètre
8 AWG (10mm²) : ~3-5 USD/mètre ✅ Recommandé
6 AWG (16mm²) : ~5-8 USD/mètre (idéal)
```

#### Fusibles haute intensité

**Mega Fuse 250A :**

```
Amazon : "250A mega fuse"

```

## ✅ CHECKLIST ACHATS

### Avant de commander

- [ ] Type batterie choisi (LiFePO4 recommandé)
- [ ] Capacité confirmée (200Ah minimum)
- [ ] BMS inclus et spécifié (200A continu)
- [ ] Voltage correct (24S = 76.8V pour LiFePO4)
- [ ] Chargeur compatible commandé (87.6V)
- [ ] Connecteurs adaptés (Anderson SB350)
- [ ] Câbles bonne section (8 AWG minimum)
- [ ] Fusible 250A commandé
- [ ] Délai livraison accepté (20-60 jours Chine)
- [ ] Budget frais douane prévu (+25-35%)
- [ ] Certificats sécurité vérifiés (UN38.3)
- [ ] Garantie confirmée (minimum 1 an)
- [ ] SAV/Support disponible
- [ ] Avis vendeur consultés (>4.5 étoiles)
