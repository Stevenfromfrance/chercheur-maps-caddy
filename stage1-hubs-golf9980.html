Validation manuelle Stage1 · Golf 9980

Checklist débutant : ouvrir Ghidra → Ctrl+G → coller l’adresse 80… → regarder la grille / le commentaire → File → Save.

Brouillon reverse — repères pour lire le soft en Ghidra / WinOLS. Ce n’est pas une carto à flasher. Ne pas écrire ces zones « au hasard » dans un bin véhicule.

Adresses : WinOLS vs Ghidra

  • WinOLS : offset flash (6 hex) — ex. 1CFFC0
  • Ghidra : toujours 80xxxxxx — ex. 801CFFC0 (pas 1CFFC0, pas A01CFFC0)
  • Vue PFLASH A0… = axes / pointeurs TriCore — ne pas utiliser pour Ctrl+G

HIGH = début de map probable. MEDIUM = pointeur dans une map connue (pas forcément le début) → commentaire seulement, surtout ne pas rename AccPed.
