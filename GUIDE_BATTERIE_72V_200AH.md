## 🎯 OPTIONS RECOMMANDÉES

### Option 1️⃣ : LiFePO4 24S 200Ah ⭐ **MEILLEUR CHOIX**

#### Spécifications
```
Configuration : 24S (24 cellules en série)
Tension nominale : 76.8V (72V système)
Tension chargée : 87.6V (3.65V/cellule)
Tension minimale : 60V (2.5V/cellule)
Chimie : LiFePO4 (Lithium Fer Phosphate)
Cellules : 3.2V 200Ah par cellule
```

#### ✅ Avantages
- **Très sûr** : Chimie la plus stable, ne s'enflamme pas
- **Longue durée** : 3000-5000 cycles (vs 800-1000 pour Li-ion)
- **Température** : Fonctionne de -20°C à +60°C
- **Coût/cycle** : Meilleur rapport sur le long terme
- **Stable** : Courbe de décharge plate

#### ❌ Inconvénients
- **Poids** : 100-120 kg pour 200Ah
- **Volume** : Plus volumineux que Li-ion
- **Prix initial** : Plus cher à l'achat

#### 💰 Prix estimé : 3000-5000 USD / EUR
**Énergie : 14.4 kWh (200Ah × 72V)**

---

### Option 2️⃣ : Li-ion NMC 20S 200Ah

#### Spécifications
```
Configuration : 20S (20 cellules en série)
Tension nominale : 72V (74V réel)
Tension chargée : 84V (4.2V/cellule)
Tension minimale : 60V (3.0V/cellule)
Chimie : Li-ion NMC/NCM
Cellules : 3.6-3.7V 200Ah par cellule
```

#### ✅ Avantages
- **Léger** : 70-90 kg pour 200Ah
- **Compact** : Densité énergétique supérieure
- **Performance** : Meilleure décharge à froid
- **Prix** : Souvent moins cher que LiFePO4

#### ❌ Inconvénients
- **Durée de vie** : 800-1500 cycles seulement
- **Sécurité** : Plus sensible aux chocs et températures
- **Dégradation** : Perd capacité plus rapidement
- **BMS critique** : Protection absolument nécessaire

#### 💰 Prix estimé : 2000-4000 USD / EUR
**Énergie : 14.4 kWh (200Ah × 72V)**

---

### Option 3️⃣ : LTO (Lithium Titanate) 💎 **PREMIUM**

#### Spécifications
```
Configuration : 32S (32 cellules en série)
Tension nominale : 76.8V (2.4V/cellule)
Tension chargée : 83.2V (2.6V/cellule)
Tension minimale : 64V (2.0V/cellule)
Chimie : LTO (Li4Ti5O12)
```

#### ✅ Avantages
- **Cycles extrêmes** : 10,000-20,000 cycles !
- **Charge rapide** : Peut charger en 10-15 minutes
- **Sécurité maximale** : Impossible à enflammer
- **Température** : -40°C à +60°C
- **Quasi-éternelle** : Dure 20+ ans

#### ❌ Inconvénients
- **Prix** : 2-3× plus cher que LiFePO4
- **Densité** : Plus lourd et volumineux
- **Rare** : Difficile à trouver
- **Voltage bas** : 2.4V/cellule (besoin 32 cellules)

#### 💰 Prix estimé : 8000-12000 USD / EUR
**Usage : Taxis, véhicules commerciaux uniquement**

```
DANGERS :
1. Court-circuit cellules → Incendie

4. Connexions faibles → Surchauffe
5. Boîtier non-isolé → Chocs électriques

CONSEILS :
✅ Utiliser gants isolants
✅ Travailler dans espace ignifuge
✅ Avoir extincteur à portée
✅ Mesurer chaque cellule avant assemblage
✅ Configurer BMS avant première charge
✅ Tester avec faible courant d'abord

## 🔌 CHARGEUR REQUIS

### Spécifications chargeur

```
Tension sortie : 87.6V (3.65V/cellule)
Courant charge : 20-40A (C/10 à C/5)
  → 20A = charge lente (10h)
  → 40A = charge normale (5h)
  → 80A+ = charge rapide (2-3h)

Connecteur : Anderson compatible batterie

Prix chargeur :
- 20A (2kW)  : 200-400 USD
- 40A (3.5kW): 400-700 USD
- 80A (7kW)  : 800-1500 USD
```

#### Pour Li-ion 20S (72V nominal)
```
Tension sortie : 84V (4.2V/cellule)
Courant charge : 20-40A recommandé

⚠️ ATTENTION : Voltage différent de LiFePO4 !
Ne pas utiliser chargeur 87V sur Li-ion 84V
→ Risque d'incendie/explosion
```

## 🚚 TRANSPORT & DOUANES

### ⚠️ Batteries lithium = Matière dangereuse

#### Réglementations
```
Transport maritime : OK
  → Classe 9 (UN3480/UN3481)
  → 20-60 jours livraison
  → Moins cher

Transport aérien : LIMITÉ
  → Restrictions strictes
  → Batterie < 300Wh souvent refusée (la vôtre = 14400Wh !)
  → Très cher si accepté

Transport terrestre : OK
  → Camion spécialisé
  → Si vendeur local/régional
```

#### Frais douanes (variables selon pays)
```
Droits de douane : 0-10% valeur
TVA/Taxes       : 5-25% valeur
Frais gestion   : 50-200 USD

Exemple 4000 USD batterie :
→ Douane 10% : 400 USD

─────────────────────
TOTAL        : 5300 USD

⚠️ Prévoir 25-35% de plus que le prix batterie

### Pourquoi LiFePO4 ?
1. **Sécurité** : Essentiel pour haute puissance (5000W)
2. **Durabilité** : 3000+ cycles = 10+ ans usage
3. **Fiabilité** : Moins de pannes que Li-ion
4. **Valeur** : Meilleur coût sur durée de vie

### Achat recommandé
1. **Premier choix** : Assembleur local (garantie + SAV)
2. **Deuxième choix** : Aliexpress vendeur réputé (LLT Power, Daly)
3. **Troisième choix** : Amazon (plus cher mais retour facile)
