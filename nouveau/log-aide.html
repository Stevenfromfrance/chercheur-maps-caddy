Ordre conseillé pour valider Stage1 daily (launch = bonus).

  1. PRIORITÉ ROUTE_RAIL — couple + rail consigne/réel
  2. PRIORITÉ ROUTE_TURBO — MAP consigne/réel sous charge
  3. PRIORITÉ VILLE — confort partiels (pas on/off)
  4. OK SI RESSENTI HARCUT — cut ~4800 en roulant
  5. BONUS DEPART — launch V3 ITALIE
  6. BONUS ROUTE_INJ — air mass / fumée / IQ si canal trouvé
Avant chaque session
  • Note soft flashé : V2 / V3 ITALIE / ACE / ORI
  • Moteur chaud
  • Route fixe (même départ / même fin)
  • VCDS → 01-Engine → Advanced Measuring Values
  • Max ~12 canaux (sinon échantillonnage trop lent)

  • Plein gaz = en charge (pas frein moteur)

  • Envoie le CSV brut, pas une photo d’écran
  • Précise ASR ON/OFF
